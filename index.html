DeepSeek Harness 开源：GitHub 史上最快涨星，Agent 框架进入「安卓时刻」

8 月 13 日晚，DeepSeek 正式发布开源智能体框架 Harness（DSH）v0.1 开发者预览版，以 MIT 协议开源。官方给出的定位公式是「Model + Harness = Agent」——模型负责推理，Harness 负责调度工具、管理状态、执行闭环。其「一切皆插件」架构基于具有时空可组合性的 Cordis 插件系统，模型、工具、沙箱、存储、调度、UI 均可独立替换。发布 1 小时即破 2 万星，24 小时约 4.6 万星，刷新 GitHub 史上最快涨星纪录（此前纪录为 Grok-1 的约 1.2 天、DeepSeek R1 的 5.7 天），被社区称为「AI 的安卓时刻」与「国产版 Codex」。

阿里开源 Qwen3.8-2.4T-A95B：首次开放 Max 级旗舰权重，PaperBench 领跑

8 月 13 日，阿里千问团队正式开放 Qwen3.8-2.4T-A95B 模型权重，这是 Qwen-Max 级别模型首次开源，也是本轮新品潮中体量最大的选手。它是 2.4 万亿参数的 MoE 模型，每 token 激活 950 亿参数，每个 MoE 层 512 个专家。官方云端版在 PaperBench（论文复现）取得 93.0 分，高于 GPT-5.6 Sol、Fable 5 与 Claude Opus 4.8；OSWorld-Verified（电脑操作）86.1 分居参评模型首位。开源版为纯文本、思考模式，采用自定义 Qwen3.8-Max License——超 1 亿月活或月收入超 2000 万美元的商业产品需展示模型名称。

架构
Qwen3.8-2.4T 架构：混合注意力，Unsloth 量化至 397GB 可本地跑
Qwen3.8-2.4T-A95B 延续 Qwen3.5 的混合注意力架构——92 层中约 3/4 为 Gated DeltaNet（线性注意力）、1/4 为 Gated Attention（全注意力），原生 262K 上下文、可扩至约 1M，默认思考模式运行。第三方团队 Unsloth AI 已用动态 1-bit 分层量化将 4.9TB 的模型压缩至 397GB（缩减 91%），设备内存 + 显存合计 410GB 以上即可本地运行。更小杯的 Qwen3.8-27B 也已预告。

DeepSeek Harness 对标 Codex/Claude Code：一切皆插件，四种运行模式
Harness 直接对标 OpenAI Codex 与 Anthropic Claude Code，主打编程与办公场景。它提供四种运行模式：标准（完整工具组合）、PTC（程序化工具调用，由模型生成代码组合多轮调用）、极简（仅 shell + 文件编辑，用于基准测试）、创造（运行时检查并组合新插件）。可追溯性是其亮点——模型看到的系统提示词、思维链、工具调用与结果、子 Agent 调度，均记录在仅追加（append-only）的会话日志中，支持恢复、分叉、检索与回放。快速体验命令：npx @deepseek-ai/dsh web。
