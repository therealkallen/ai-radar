OpenAI 发布 GPT-6.2 Astra 与 Sol，主攻专业工作和成本效率

OpenAI 11月17日发布 GPT-6.2 Astra 与 Sol，分别面向复杂专业项目和高频日常工作。官方称新模型改善文档、表格、幻灯片、编程及计算机操作，输出 token 更少，并公布定价及安全评估。性能数字属于厂商自测，实际企业部署仍需单独验证。

模型与技术进展

微软 Ignite 推出六款专用 AI 模型，降低对外部模型依赖

微软在 Ignite 公布六款覆盖编码、网络安全、图像及语音的专用模型，包括 MAI Code 2、MAI Code 2 Flash 和 MAI Cyber 2 Flash。微软声称在选定任务上具备明显成本优势，且企业可授权模型权重在 Azure 内定制；相关性能与价格比较仍应视为厂商口径。

国内 AI 动态

路透调查：中国 AI 蒸馏技术走向产业化，引发跨境模型使用争议

路透11月17日调查超过300份论文、专利、招聘及政府文件，发现中国研究团队利用美国模型输出生成训练数据，辅助 Qwen 等较小模型训练。蒸馏本身并非违法，报道同时呈现中美双方对知识产权边界的不同观点；不应把所有蒸馏行为直接写成违规窃取。

AI 与金融

美联储理事 Barr 警告 AI 智能体可能加速银行挤兑

美联储理事 Michael Barr 11月16日讲话指出，AI 在交易中的趋同行为可能放大市场波动，银行也可能难以确认代理客户操作的智能体是否获得授权。其进一步警告高速自动交易可能使挤兑超过传统保护措施的响应能力；这是风险分析，不是已经发生的金融事故。

行业进展
GitHub Copilot 活动接入 Microsoft Agent 365，强化企业智能体审计
GitHub 11月17日宣布，企业可将 Copilot 智能体活动流送至 Microsoft Agent 365，统一观察来自不同 Copilot 客户端的操作记录。对大规模部署编码智能体的企业，新增集中审计与治理路径；这属于监控集成，不意味着 Agent 365 自动批准所有智能体行为。

行业进展
GitHub Copilot Evals 开放公测，支持对提示词、技能和工具做回归评估
GitHub 11月17日将 Copilot Evals 推向公开预览，开发者可比较提示词、模型、skills 与工具变更后的表现，查看失败执行步骤及预期与实际证据差异。这为企业自建智能体提供更可复现的质量检查，但目前仍是预览功能，不能将评估分数等同生产可靠性。

行业进展
GitHub Copilot 推出浏览器操作预览，智能体可跨代码与网页执行任务
GitHub 11月17日宣布配合 Copilot Chrome 扩展，浏览器使用能力在 Copilot CLI、App、VS Code 与 JetBrains 开放公开预览。开发者可在编程工作流中让智能体与网页交互；涉及登录态、敏感页面和写入操作时仍需企业权限及安全审查。

GitHub Copilot 代码审查加入自适应深度与密钥检测
GitHub 11月17日更新 Copilot code review，推出根据 PR 情况调整审查力度的 Adaptive 选项，并强化跨仓库上下文及密钥检测。企业可用来优化审查成本和覆盖范围，但自动建议仍需人工核对，尤其是涉及安全或业务逻辑的变更。

中国商务部回应美国 AI 芯片新限制，警告可能采取反制
11月17日中国商务部表示反对美国进一步限制中国企业获取先进 AI 芯片的新规则，并称若美方坚持实施将采取反制措施。当前属于政策表态及条件性警告，不应写成反制措施已经落地；出口限制对跨境算力采购和供应链规划的影响仍需跟踪。

纽约州提出法官 AI 虚构引证问责法案，针对裁判文书真实性
纽约州议员提出司法 AI 问责与诚信法案，拟将法官明知或鲁莽地在裁判文书引用虚构法律依据认定为不当行为，并可能触发纪律处分。法案并未禁止司法系统使用 AI，目前仍是提案而非生效法律，反映法律职业对生成式内容核验责任的关注。
