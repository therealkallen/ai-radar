Anthropic 确认提交 S-1，拟以 ANT 代码在纳斯达克上市

Anthropic 10月26日宣布已向美国SEC提交与拟议IPO有关的S-1注册声明，计划以ANT为股票代码在纳斯达克全球精选市场挂牌。公司明确表示发行股数和价格区间尚未确定，注册声明也尚未生效。本次是申报状态的官方确认，不能解读为IPO获批或已完成，更不能沿用旧传闻中的估值和募资金额。

Kimi K3.1 Pro 上线产品与 API，完整权重计划 11 月 4 日前发布

月之暗面10月24日公布Kimi K3.1 Pro，面向长程编程、3D创作与金融研究，提供百万token上下文及Highspeed版本。官方说明模型已进入Kimi、Kimi Work、Kimi Code和API；完整权重计划11月4日前发布，当前不能写成已开放下载。企业版管理员可启用新模型，首发默认关闭，需结合组织实际任务评估。

Qwen Code 0.26.1 强化工作区恢复，修复群聊会话隔离

Qwen官方仓库10月24日发布Qwen Code 0.26.1稳定版，列出托管会话的空闲时手动上下文压缩、恢复状态提示、检查点历史和会话生命周期界面等更新。发布说明还将群聊线程范围下的会话隔离修复标成不兼容变更。它关注持续工作区的可恢复性，团队升级时应核对原有群聊隔离与会话配置，不应将nightly特性混入稳定版。

OpenAI 公开 Habitat 存储扩展细节：多租户隔离与全球缓存
OpenAI 10月23日发布Habitat存储工程系列第二篇，介绍Azure Cosmos DB从多租户到单租户、再回到可迁移多租户的取舍。文章重点包括热点租户限流、服务质量控制、区域缓存、变更数据捕获和Rust代理优化。它提供的是现有系统的工程实践，不是新模型发布；其中延迟与规模数据是公司自身环境的测量，不能直接套用到其他企业。

HN 讨论模型降价：竞争、推理效率与可持续性各有解释
10月26日的Hacker News帖子围绕模型降价展开讨论：部分评论归因于开源模型竞争，另一些提出推理优化、缓存和算力利用率等解释，也有人质疑定价能否持续。它反映开发者对调用成本的关注，不能据此断言厂商真实利润、补贴规模或监管动机。本期未采用实时票数，也没有把帖子标题中的降幅写成已核实的统一调价。
