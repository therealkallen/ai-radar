Google 公布 Gemini 4 Carbon，先向部分网络防御伙伴开放

Google公布Gemini 4 Carbon，强调长程软件工程及漏洞发现、验证和修补能力。官方表示先向部分网络防御人员开放，并通过Fairwind逐步扩展可信伙伴，普通开发者、企业和消费者仍待后续推出。公布的首发价为每百万输入2美元、输出10美元；评测与内部使用结果属厂商口径，不能据此认定所有用户现已可调用。

Qwen Code 0.26.4 增加独立工作树，改进交互视图与 PR 核验

Qwen官方仓库10月29日发布0.26.4稳定版，为托管主会话加入独立Git工作树，并让生成式界面以可交互视图呈现。PR核验报告开始记录模型、CLI和技能版本，另修复离线恢复与部分配置静默丢失问题。团队可据此检查会话隔离和报告可追溯性；同日nightly后续功能不应混入稳定版说明。

OpenAI 更新 Model Spec，以五项价值组织模型行为准则

OpenAI 10月29日更新公开Model Spec，以忠于人类意图、减少伤害、诚实透明、人的自主性和关怀五项价值组织准则，并补充上下文、监督和自主性指引，调整默认行为与部分风格要求。这是公司对模型目标行为的规范说明及持续训练方向，不是法律监管文件，也不表示所有线上模型已完整实现新版规范。
