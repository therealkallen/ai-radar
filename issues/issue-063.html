DeepSeek 将搜索、文件、语音与安全能力开放为 API

DeepSeek 11月13日发布应用功能 API，开发者可通过 V4.1-Flash 的 Messages、Responses 和 Chat Completions 接口启用网页搜索、文件输入、URL读取与安全检测，另有 OCR、ASR、TTS 独立接口。官方说明额外工具调用另行收费，面向公众的应用需启用安全检查。

模型与技术进展

llama.cpp 与 ggml 发布 v1.0，正式约定 API 兼容性规则

ggml-org 11月13日正式发布 llama.cpp 和 ggml 的 v1.0.0，采用语义化版本规则：公开 C API 的破坏性变更触发主版本更新。此次还移除旧接口、加入 MoE 缓存与语音端点，并加强 llama-server 安全性。重点在开发者依赖稳定性，不应误称模型本身升级。

GitHub Copilot 上线 Gemini 4 Hydrogen，支持企业模型策略

GitHub 11月13日宣布 Gemini 4 Hydrogen 在 Copilot 中一般可用，覆盖 VS Code、CLI、编码智能体和多种 IDE，企业管理员可通过模型策略控制访问。官方提醒逐步推送，并按提供商价格计费。该事件是第三方平台正式接入，与62期Google模型首次发布分属不同阶段。

GitHub 11月13日宣布 Copilot App 现可连接 GitHub Enterprise Server，处理远程仓库、Issues 和 PR。该功能从可选预览转为一般可用，要求 Copilot App 1.2.0 及以上，且 GHES 暂不支持云端会话；这对企业代码治理和本地仓库访问边界具有实际影响。
